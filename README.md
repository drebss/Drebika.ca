# drebika.ca

A personal working archive built with Astro and edited through Pages CMS.

## Local development

```bash
npm install
npm run dev
```

## Content

Entries live in `src/content/entries/`. Each Markdown file can represent a project,
prototype, artwork, concept, note, experiment, or fragment.

## Deploy

Connect this repository to Cloudflare Pages.

- Build command: `npm run build`
- Output directory: `dist`
- Node version: 22

## Pages CMS

Connect the repository at Pages CMS. The configuration is stored in `.pages.yml`.
